# v1.0.0 开发关卡与验证报告

日期：2026-10-11。基线 HEAD：`09a178e41cf3b336f7730899c93b389343caf689`。本轮是 **P0 可行性调查与工具交付，不是 v1.0.0 功能完成报告**。

## 发布决定

真人分别测试现有自定义 A 和 Apple 视频 A；独立桌面 B 的原生配置未使真实锁屏持续播放 A。P0 失败，P1—P4 未实施。详见 [可行性记录](v1.0.0-separation-feasibility.md)。支持白名单为空，不发布完整分离模式，不更新应用版本号或替换已安装的 v0.8.5 / build 13。

## 现有代码审查与调用关系

| 模块 | 已确认行为 | 分离所缺能力 |
| --- | --- | --- |
| AppModel / ContentView | 新视频输入、就绪状态、裁剪、环境、转换及确认 | 草稿/已应用/观察状态与平行互斥模式 |
| AppModel / Services | 转换、历史替换、视频备份恢复，SHA 校验与原子安装 | 独立 B、完整系统配置事务与恢复 |
| HistoryView / Services | 原件/已编码历史、缩略图重试、命名、删除、再次安装 | 分离模式下保留 B 的已验证路径 |
| GeometryDiagnostics / EncoderSupport | 原生画布来源、几何约束、编码器完整性 | 不应被误用于推断系统分离 |
| WallpaperOperationTimeline | 三种视频操作的备份、安装、回滚及单次重载 | 多资源持久事务及配置回滚 |
| LockBehaviorDiagnostics / SystemEventProbe | 有界只读意外锁屏报告 | 不能证明实际锁屏内容或动画 |

现有写入关系：`AppModel` 的转换/历史替换/备份恢复入口 → `AerialService` 备份归档 → `WallpaperOperationSafety.install` 校验、安装或回滚 → 单次 `reloadWallpaperAgent`。没有现成独立桌面图片 API 调用或私有 Store 写入后端。以上生产源码、历史格式、原生画布、诊断 schema 及发行工作流本轮均未修改。

新增工具关系：CLI 参数校验 → 稳定有界文件读取/公开桌面读取 → 递归脱敏 → 私有快照保存与读回校验 → 可选有界快照比较。工具不链接生产应用，不执行锁屏、重载或安装。

## 未实施与未验证

- 没有实现模式切换、独立 B 托管、历史 A 保留 B、完整配置恢复、外部变化处理或配置诊断 UI；不能将视频备份恢复等同于整套系统配置恢复。
- 没有真实 UI 生成且行为通过的兼容夹具/白名单；禁止用合成 plist 模板代替。
- 自然屏保、睡眠、重启、五轮成功锁屏、外屏、多 Space、电池/充电矩阵未通过验收；本轮两次真人负面观察只适用于所测路径与系统。
- 原生 API 设置 B、私有 Store 自动提交/回滚、事务故障注入与崩溃恢复测试未执行，因为尚未进入 P1/P2。
- 旧版意外锁屏和延迟比例异常没有因本轮调查被宣布修复。

独立 reviewer 发现并由执行 worker 修正：未知键子树遗漏、本地 NSColor 信息丢失、fsync 错误遗漏、比较读取缺乏大小/schema 限制。复审没有 P0 工具范围的阻断项。真实系统分离阻断仍存在。
