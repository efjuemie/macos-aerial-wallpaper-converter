## 自动验证

本版最终九组自动测试全部通过：`test_lock_behavior_logic`、`test_wallpaper_operation_timeline`、`test_appmodel_input_lifecycle`、`test_input_readiness`、`test_environment_logic`、`test_encoder_integrity`、`test_geometry_logic`、`test_temporal_sample_groups`、`test_video_drop_ui_structure`。使用合成证据、注入文件操作与无害子进程，没有执行真实 pkill、会话锁定或修改用户旧服务。

新增测试实际覆盖短命命令的大量输出末尾 sentinel、输出截断、启动前取消、运行中取消、超时及父进程退出后忽略 TERM 的子进程清理。安全安装测试执行生产共用的 helper，覆盖未验证备份阻止覆盖、安装抛错、安装 SHA 不符、回滚抛错和 SHA 不符、成功安装时间及单次重载 gate；时间线、schema、缺失状态、数据来源和脱敏另有断言。

编译测试使用 `swiftc <相关源文件> Scripts/test_*.swift -o <临时目录/测试程序>` 并执行产物；单文件拖放接线测试使用 `swiftc -parse-as-library`。源文件列表及每项运行命令完整列于 `.github/workflows/publish-v0.8.5.yml`。`git diff --check`、`plutil -lint Resources/Info.plist`、全源文件类型检查通过。独立 read-only reviewer 最终无阻断项。

本地 arm64 Release 构建通过，最低部署 macOS 13，应用版本 `0.8.5 / build 13`。开发机默认的 macOS 27 SDK 缺少 SwiftUI 宏插件，本轮在独立构建 shell 中给 SwiftPM 指定现有的 macOS 26.5 SDK，未修改系统开发环境选择：

```bash
swift() {
  /Library/Developer/CommandLineTools/usr/bin/swift "$@" \
    --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
}
export -f swift
./build_app.sh
Scripts/package_release.sh
```

以上函数用于 Bash 构建 shell。App 与内置 arm64 encoder 的 ad-hoc 签名校验通过；打包脚本通过 encoder manifest SHA、ZIP 完整性以及 DMG 挂载后 App/Applications 快捷方式检查，生成 v0.8.5 ZIP/DMG。没有 Developer ID 签名或 Apple 公证。GitHub 发布工作流还会独立重建、执行同一组回归并验证发行包。

在开发机通过实际 App 界面完成只读导出烟测：展开“排查意外锁屏”，保留 unknown、不填写事件时间，直接点击导出，约 3 秒后显示成功提示。报告 schema=1、appVersion=0.8.5、classification=unknown、confidence=insufficient；pmset 快照可用，系统日志达到上限并明确标为 truncated；无法可靠读取的设置保持 unavailable。未修改壁纸或系统设置，原始系统日志没有上传。该烟测仅证明诊断入口可用，不是意外锁屏异常的复现。

## 真机对照步骤（未执行的项不算通过）

在同一台受影响设备记录系统版本、电源、外屏、合盖、屏保计时、显示器闲置关闭及密码策略。先选实际事件类型并记录大致时间，随后在“排查意外锁屏”导出报告。日志缺失记为无法判断。

1. A：Apple 原始壁纸基线，记录观察开始/结束及发生次数。
2. B：Debug 构建启动时设置 `WALLPAPER_CONVERTER_SKIP_RELOAD=1`，替换后手动在系统设置重选壁纸；记录跳过重载与安装结果。Release 忽略该变量。
3. C：相同视频和设置，使用正常单次重载；与 B 对照。
4. D：仅发现旧服务时，由用户主动点击“停用旧脚本”，保留配置后做前后对照。

每组时间应覆盖已知触发间隔；未知时先做长时间空闲观察。代表性覆盖电池/外接电源、单/多屏、合盖、退出应用、睡眠→唤醒；至少完成 5 次锁屏→解锁。同时检查裁剪位置、桌面立即和约 5 秒后的比例、黑屏与第二次播放、历史替换及备份恢复。记录“未观察到”不能写成“已修复”。

开发机为 Apple Silicon、macOS 26.6.2（25G83）；当前未取得受影响设备，上述长时间/锁屏/睡眠/合盖对照均待用户真机执行。诊断可读性与合成测试不能替代它们。

## 回退与数据保留

应用替换异常时，在“恢复备份”选择替换前版本或从历史壁纸恢复可信原件，再到系统设置重新选择壁纸。版本回退可安装 [v0.8.4](https://github.com/efjuemie/macos-aerial-wallpaper-converter/releases/tag/v0.8.4)，保留 Application Support 中的原件归档、Backups、native-canvases.json 和诊断文件。不要通过删除最早原件/记录掩盖几何或播放异常。旧 LaunchAgent 的停用配置保留在原目录的 `.disabled` 或带编号文件中；恢复前先检查它是否确有必要。
